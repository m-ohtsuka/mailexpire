sendmail スプールに入っているメールを expire するプログラムです。スプー
ルファイルをロックするので（恐らく）安全に expire できます。

書式)
mailexpire <file> [days]

file は，スプールファイルを指定します。この引数は必須です。

days は expire する日数を指定します。90 を指定すると過去 3 ヶ月以内の
メールは残し，それより古いメールを削除します。

以下 Hacker 向け

mailexpire は以下のようなアルゴリズムで expire を実行します。

1. flock() || fcntl() によるロックを行います。

2. sendmail のスプールは '\nFrom ' によって区切られています。
mailexpire はこの行（いわゆる Unix From）を見つけ出し，その日付を読み
ながら該当するメールの位置までファイルポインタを動かします。

3. ファイルポインタから以下をテンポラリファイルに書き出します。テンポ
ラリファイルはスプールディレクトリに吐かれます。

4. テンポラリファイルを，メールスプールファイルに rename します。

5. ロックを解除します。

ファイルロックは Linux は fcntl()，それ以外は flock() としています。
local MDA に mail.local を使っているものは flock() であると考えていい
と思います。
